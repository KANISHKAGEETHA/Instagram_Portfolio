How to use
1. Open this folder in VS Code (File > Open Folder).
2. Right-click index.html > Open with Live Server (install the Live Server extension), or just double-click index.html.
3. Put your photos in the images folder and replace each photo slot in index.html.
   Example: change
     <button class="ph" style="--c1:#B03A6B;--c2:#4A1633"><span class="hint">...</span></button>
   to
     <div class="ph has"><img src="images/photo1.jpg" alt="Kanishka"></div>
4. Edit your text directly in index.html.
